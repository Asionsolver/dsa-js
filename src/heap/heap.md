# Heap Tree

- Complete Binary Tree
  - Only 2 children per node
  - All levels are fully filled
  - Compact tree layout with minimal height
- Nodes are added from left to right

## Types of Heaps

- Max-Heap
  - Parent node is greater than or equal to its children
  - Root node contains the maximum value
  - Example: [50, 30, 20, 15, 10, 8, 16]

```
        50
       /  \
     30    20
    / \    / \
   15 10  8  16
```
